## 🚀 Getting Started with the Web Portfolio

To run the interactive web application locally:

```bash
cd portfolio
npm install
npm run dev
```

The application will be served at `http://localhost:5173`.

### Build & Preview

```bash
cd portfolio
npm run build
npm run preview
```
